# YGO Cards

App mobile feito com React Native + Expo que consome a API pública
YGOPRODeck e exibe uma lista de cartas de Yu-Gi-Oh!.

## Funcionalidades
- Busca de cartas na API YGOPRODeck
- Lista com imagem, nome, tipo e ATK/DEF
- Indicador de carregamento e tratamento de erro

## Tecnologias
- React Native
- Expo
- API: https://db.ygoprodeck.com/api/v7

## Como rodar
1. Instale as dependências: `npm install`
2. Inicie o projeto: `npx expo start --go`
3. Escaneie o QR code com o app Expo Go
